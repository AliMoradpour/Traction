# DOGFOOD CHECKLIST

Daily usage checklist for internal dogfooding.

---

## Morning Planning

- [ ] Open app — verify cold start < 3 seconds
- [ ] Check Today screen — verify tasks load
- [ ] Review AI Daily Brief (if available)
- [ ] Create new tasks for the day
- [ ] Set priorities on tasks
- [ ] Link tasks to goals

## Goal Creation

- [ ] Create a new goal via 4-step wizard
- [ ] Verify goal appears in Goals list
- [ ] Add milestones to goal
- [ ] View goal projection
- [ ] Check goal health score

## Task Execution

- [ ] Start a focus session from Today
- [ ] Verify adaptive duration calculation
- [ ] Let timer run for 5+ minutes
- [ ] Test "Why am I stuck?" resistance flow
- [ ] Complete focus session
- [ ] Verify task marked as completed
- [ ] Test pause/resume during session

## Focus Session

- [ ] Start session from Smart Start
- [ ] Test session with low readiness score
- [ ] Test session with high momentum
- [ ] Abandon a session — verify behavior tracked
- [ ] Return to interrupted session — verify recovery flow

## AI Planning

- [ ] View Daily Brief
- [ ] View Weekly Review
- [ ] Accept an AI recommendation
- [ ] Dismiss an AI recommendation
- [ ] Test stuck analysis (from focus session)
- [ ] Check AI usage dashboard

## Behavior Dashboard

- [ ] View daily metrics
- [ ] View weekly trends
- [ ] Check 6 behavior indicators
- [ ] Review burnout risk
- [ ] Review procrastination profile
- [ ] Get AI coaching recommendations

## Weekly Review

- [ ] Complete end-of-day reflection
- [ ] Review weekly wins
- [ ] Review commitments
- [ ] Check behavior patterns

## Notifications

- [ ] Verify notification badge count
- [ ] Mark notification as read
- [ ] Mark all as read

## Offline Usage

- [ ] Turn off WiFi/data
- [ ] Verify offline banner appears
- [ ] Try to create a task (should fail gracefully)
- [ ] Turn WiFi back on
- [ ] Verify automatic recovery

## App Restart

- [ ] Kill app completely
- [ ] Reopen app
- [ ] Verify auth state preserved
- [ ] Verify on last screen
- [ ] Verify focus session recovery (if active)

## Developer Tools

- [ ] Tap version 5 times to access developer settings
- [ ] Export logs — verify JSON report
- [ ] Check API environment display
- [ ] Reset onboarding — verify flow restarts

---

**Run this checklist daily for the first week of dogfooding.**
