# وضعیت، مشکلات شناخته‌شده و نقشهٔ راه

تاریخ بازبینی: ۲۷ آبان ۱۴۰۵ (۱۸ نوامبر ۲۰۲۶)

## وضعیت فعلی

| بخش | وضعیت |
|---|---|
| سرور (API) | ✅ کامل و پایدار؛ ۱۹ تست و آزمون سرتاسری ۱۰۲ مسیر موفق |
| اپ Expo (وب، Expo Go) | ✅ کار می‌کند؛ اندروید هنوز ساخته و آزمایش نشده؛ طراحی «آرام و گرم» روی همهٔ صفحه‌ها؛ ۱۶ تست |
| وب‌اپ نصب‌شدنی آیفون (PWA) | ✅ آماده (manifest، service worker، آیکن‌ها) |
| برنامه‌ریزی هفته و ماه، مرور ماهانه | ✅ |
| میزبانی (Render + Neon) | ✅ پیکربندی آماده (`render.yaml`)؛ راهنما: `docs/DEPLOY.md` |
| CI | ✅ روی هر push و Pull Request |
| اپ بومی Swift | ⏳ برنامه‌ریزی شده، شروع نشده |
| وب‌سایت معرفی | ⏳ برنامه‌ریزی شده (`apps/website/`) |
| یادآورها و اعلان push | ⏳ تنظیمات در `render.yaml` هست، کد سرور هنوز نیست |

## صفحه‌هایی که کامل بازطراحی شده‌اند

خوشامد، ورود، ثبت‌نام، رمز، آشنایی، معرفی، امروز، جلسهٔ تمرکز، زبانهٔ تمرکز، پیشرفت، هدف‌ها، ساخت هدف، جزئیات هدف، شما، کار جدید، جزئیات کار.

بقیهٔ صفحه‌ها (برنامهٔ روز، بازبینی، مرورها، صفحه‌های عادت و شتاب، ویرایش هدف و…) رنگ‌ها، آیکن‌ها و نوشتار جدید را دارند اما چیدمانشان هنوز قدیمی است.

## مشکلات شناخته‌شده

| مشکل | شدت | توضیح |
|---|---|---|
| مخزن `Traction` عمومی (public) بود | بالا | باید خصوصی شود؛ نگاه کنید به [security.md](security.md) |
| SMTP برای ایمیل بازنشانی در تولید تنظیم نیست | متوسط | بدون آن، ایمیل بازنشانی ارسال نمی‌شود |
| تأیید ایمیل وجود ندارد | پایین | تصمیم محصولی لازم است |
| ذخیرهٔ رمز در iCloud Keychain کار نمی‌کند | پایین | در Expo Go ممکن نیست؛ در اپ Swift با associated domains |
| ۱۵ جای کد هنوز تاریخ را به شکل UTC می‌سازند | متوسط | صفحه‌های امروز و ساخت کار درست شده‌اند؛ بقیه باید به `src/lib/dates.ts` منتقل شوند |
| ۱۴۸ هشدار lint | پایین | بدون خطا |
| ادغام `dev` در `main` | — | پس از بازبینی |

## نقشهٔ راه پیشنهادی

1. **فوری:** خصوصی‌کردن مخزن، انتقال به مک‌بوک (راهنمای PDF انتقال).
2. **راه‌اندازی آنلاین:** اجرای `docs/DEPLOY.md` (Neon + Render)، نصب وب‌اپ روی آیفون، بستن ثبت‌نام عمومی.
3. **۱۰ تا ۲۰ کاربر آزمایشی:** دادهٔ ماندگاری کاربران (retention)، بازخورد از صفحهٔ «شما».
4. **پایش:** Sentry یا مشابه برای خطاها، آمار استفاده.
5. **اپ Swift:** بازنویسی برنامه برای مک و Xcode، سپس مراحل ۰ تا ۱۰.
6. **وب‌سایت معرفی و آماده‌سازی App Store:** مراحل ۱۱ تا ۱۳.
7. **مدل درآمدی:** اشتراک (در صورت انتشار عمومی) با در نظر گرفتن هزینهٔ هوش مصنوعی.
