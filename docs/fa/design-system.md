# سیستم طراحی: «آرام و گرم»

هدف طراحی: اپی که **آرامش** بدهد، نه فشار. الهام از اپ‌های خود اپل (Reminders و Fitness) و اپ‌هایی مثل Headspace و Calm. بدون گرادیان درخشان، نئون یا شیشه‌ای، و بدون ایموجی به جای آیکن.

مرجع انگلیسی کامل: [`DESIGN.md`](../../DESIGN.md)

## رنگ‌ها

اپ خودکار از حالت روشن یا تاریک آیفون پیروی می‌کند. منبع: `apps/mobile/src/theme/colors.ts`

| نقش | روشن | تاریک | کاربرد |
|---|---|---|---|
| پس‌زمینه | `#FAF6F0` کاغذی گرم | `#191714` شب گرم | زمینهٔ همهٔ صفحه‌ها |
| سطح (کارت) | `#FFFFFF` | `#24211D` | کارت‌ها، فیلدها |
| سطح نرم | `#F2EBE1` شنی | `#2E2A25` | دکمهٔ ثانویه، چیپ‌ها |

| متن کم‌رنگ | `#6E665C` | `#B9B0A4` | توضیحات |
| آبی تِرَکشن | `#3D6BE0` | `#7C9EF2` | **فقط برای اقدام‌ها**: دکمهٔ اصلی، زبانهٔ فعال، پیوند |
| سبز مریم‌گلی | `#6E9E7E` | `#8DBB9B` | انجام‌شده، آرامش، «در مسیر» |

## تایپوگرافی

| سبک | فونت | کاربرد |
|---|---|---|
| تیترها (`displayLg`، `displayLgMobile`، `headlineMd`، `timer`) | **Nunito ExtraBold** (گرد و دوستانه) | عنوان صفحه‌ها، عدد زمان‌سنج |
| `titleMd` | Nunito Bold | عنوان بخش‌ها |
| متن (`bodyLg`، `bodyMd`، `labelSm`) | Inter | متن و برچسب‌ها |

قواعد نوشتار: **حروف عادی جمله** (sentence case)، نه حروف بزرگ؛ لحن مهربان و کوتاه («قدم به قدم»، «گیر کرده‌ای؟»).

## شکل‌ها

- گوشه‌ها: `md=14`، `lg=20`، `xl=24`، دکمه‌ها کاملاً گرد (pill).
- سایه‌ها نرم و گرم (`#3C2814` با شفافیت کم)؛ در حالت تاریک به جای سایه از حاشیهٔ نازک استفاده می‌شود.
- آیکن‌ها: **Ionicons** خطی (outline)؛ در زبانهٔ فعال توپر.

## کیت طراحی (`src/components/calm`)

| کامپوننت | کاربرد |
|---|---|
| `Page` | قالب صفحهٔ داخلی: دکمهٔ برگشت، عنوان، زیرعنوان، اسکرول، دکمهٔ ثابت پایین (`footer`) |
| `Card` | کارت سفید یا رنگی (`tint`: blue، sage، clay، sand)؛ با `onPress` قابل لمس |
| `Group` و `Row` | فهرست گروه‌بندی‌شده مثل تنظیمات آیفون؛ آیکن، عنوان، توضیح، مقدار، فلش |
| `SectionTitle` | عنوان بخش با توضیح یا اقدام سمت چپ |
| `Pill` | برچسب کوچک رنگی (مدت، اهمیت، وضعیت) |
| `StatTiles` | کاشی‌های آمار |
| `ProgressBar` | نوار پیشرفت |
| `EmptyHint` | حالت خالی با آیکن، عنوان، متن و دکمه |
| `IconButton` | دکمهٔ گرد آیکنی (نرم یا اصلی) |
| `Glyph` | جایگزین ایموجی‌های قدیمی با آیکن خطی معادل |

اجزای پایه در `src/components/ui`: `Button` (اصلی، ثانویه، شبح، خطر)، `Input` (با برچسب، خطا و اتصال به فرم).

## قواعد برای صفحهٔ جدید

1. از `Page` و کیت calm استفاده کنید، نه `StyleSheet` با رنگ ثابت.
2. رنگ‌ها فقط از `theme.colors`؛ هیچ کد رنگ hex در صفحه ننویسید.
3. هر صفحه حداکثر **یک** دکمهٔ آبی اصلی داشته باشد.
4. دکمه داخل دکمه نگذارید (روی وب خطا می‌دهد)؛ اجزای قابل لمس را کنار هم بچینید.
5. حالت تاریک را هم بررسی کنید.
