# اپ بومی آیفون (Swift)

برنامهٔ کامل و مرحله‌ای (انگلیسی): [`docs/IOS_SWIFT_PLAN.md`](../IOS_SWIFT_PLAN.md)

## هدف

یک اپ بومی با **Swift و SwiftUI** که بشود آن را در **App Store** برای همه منتشر کرد. سرور فعلی (`backend/`) بدون تغییر اساسی به آن خدمت می‌کند.

## مخزن

- `git@github.com:AliMoradpour/traction-ios-app.git` (خصوصی)، شاخهٔ کاری `dev`.
- وضعیت فعلی: فقط کامیت آغازین؛ **هیچ‌کدام از ۲۲ گام برنامه هنوز انجام نشده است**.

## ساختار برنامه‌ریزی‌شده

```
traction-ios-app/
  Package.swift            بستهٔ SwiftPM، iOS 17 به بالا
  Sources/TractionCore/    بدون رابط کاربری: کلاینت API، مدل‌ها، احراز هویت، تاریخ‌ها (تست‌پذیر)
  Sources/Traction/        صفحه‌های SwiftUI و کیت طراحی
  Tests/TractionCoreTests/
```

بدون کتابخانهٔ جانبی؛ فقط ابزارهای خود اپل (URLSession، Keychain، UserNotifications، Charts). صفحه‌ها از [design-system.md](design-system.md) و صفحه‌های فعلی Expo پیروی می‌کنند و مسیرهای API از `apps/mobile/src/api/endpoints.ts`.

## ⚠️ تغییر مهم با خرید مک‌بوک

برنامهٔ فعلی برای **ویندوز + WSL + xtool** نوشته شده، چون مکی در کار نبود؛ و برای ارسال به App Store از یک مک ابری (GitHub Actions) استفاده می‌کرد. با مک‌بوک:

- **Xcode** جای xtool و WSL را می‌گیرد: شبیه‌ساز آیفون، اجرای مستقیم روی گوشی و ارسال مستقیم به App Store.
- مرحلهٔ ۰ ساده‌تر می‌شود و مرحلهٔ ۱۳ دیگر به مک ابری نیاز ندارد.
- پیشنهاد: پیش از شروع مرحلهٔ ۰، فایل `IOS_SWIFT_PLAN.md` را برای مک بازنویسی کنیم.
