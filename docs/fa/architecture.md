## اصل‌های طراحی معماری

1. **منطق در سرور، نه در صفحه‌ها.** محاسبات (امتیاز آمادگی، اصطکاک کار، پیش‌بینی هدف، الگوهای رفتاری) و متن درخواست‌های هوش مصنوعی (prompts) همه در سرور هستند. اپ فقط نمایش می‌دهد.
2. **یک سرور برای همهٔ اپ‌ها.** اپ Expo (اندروید و وب)، وب‌اپ آیفون و اپ آیندهٔ Swift همه از یک API استفاده می‌کنند.
3. **زمان محلی کاربر.** اپ همیشه «لحظهٔ مطلق» (ISO) می‌فرستد، مثلاً شروع روز محلی کاربر، تا کار در هر منطقهٔ زمانی در روز درست بنشیند. سرور در تولید با `TZ=Asia/Tehran` اجرا می‌شود.
4. **امنیت پیش‌فرض.** همهٔ مسیرها به جز ثبت‌نام، ورود، بازیابی رمز و `health` نیاز به توکن دارند. محدودیت نرخ درخواست (rate limit) فعال است.

## جریان یک درخواست

1. کاربر در اپ دکمه‌ای را می‌زند (مثلاً «تمام شد» روی یک کار).
2. یک هوک React Query (`src/hooks/useTasks.ts`) سرویس مربوط (`src/services/task.service.ts`) را صدا می‌زند.
3. کلاینت Axios (`src/api/client.ts`) توکن دسترسی را از حافظهٔ امن (SecureStore؛ در وب: localStorage) اضافه می‌کند و درخواست را به `/api/tasks/:id/complete` می‌فرستد.
4. اگر توکن منقضی شده باشد، رهگیر (`src/api/interceptors.ts`) با توکن تازه‌سازی (refresh) توکن جدید می‌گیرد و درخواست را تکرار می‌کند.
5. در سرور، `JwtAuthGuard` توکن را بررسی می‌کند، کنترلر ورودی را با DTO اعتبارسنجی می‌کند و سرویس با Prisma پایگاه داده را به‌روز می‌کند.
6. پاسخ برمی‌گردد و React Query کش مربوط را باطل (invalidate) می‌کند تا صفحه‌ها به‌روز شوند.

## محیط‌ها

| محیط | سرور | پایگاه داده | اپ |
|---|---|---|---|
| توسعه (روی لپ‌تاپ) | `npm run start:dev` یا `start:prod` روی پورت محلی (فعلاً ۳۱۰۰) | PostgreSQL در Docker (`traction-pg`، پورت ۵۵۴۴) | Expo Go روی آیفون از طریق Wi-Fi |
| تولید | Render: `traction-api` (منطقهٔ فرانکفورت، شاخهٔ `dev`) | Neon (منطقهٔ فرانکفورت) | Render: `traction-app` (وب‌اپ استاتیک) |

> نکته: پورت ۳۰۰۰ روی لپ‌تاپ فعلی توسط پروژهٔ دیگری استفاده می‌شد؛ به همین دلیل سرور محلی تِرَکشن روی ۳۱۰۰ اجرا شد. روی مک می‌توانید هر پورت آزادی انتخاب کنید (جزئیات در [setup-mac.md](setup-mac.md)).

## ساختار پوشه‌ها

```
Traction/
├── backend/                 سرور NestJS
│   ├── src/modules/         ماژول‌های دامنه (هر کدام controller + service + dto)
│   ├── src/common/          گاردها، دکوریتورها، ابزارهای مشترک
│   ├── prisma/              schema.prisma، مهاجرت‌ها (migrations)، seed
│   └── prompts/             متن درخواست‌های هوش مصنوعی (Markdown)
├── apps/mobile/             اپ Expo (iOS، اندروید، وب)
│   ├── app/                 صفحه‌ها (Expo Router؛ ساختار پوشه = مسیرها)
│   ├── src/                 api، hooks، services، store، components، theme، lib
│   └── public/              فایل‌های وب‌اپ نصب‌شدنی (manifest، service worker، آیکن‌ها)
├── docs/                    مستندات (انگلیسی) و docs/fa (فارسی)
├── render.yaml              تعریف سرویس‌ها برای Render
└── .github/workflows/ci.yml CI گیت‌هاب
```
