# معرفی پروژه

## تِرَکشن چیست؟

تِرَکشن (Traction) یک اپلیکیشن مدیریت کار و هدف با رویکرد **آرام** است؛ برای کسانی که با شروع‌کردن کارها، تمرکز و اهمال‌کاری مشکل دارند. شعار محصول: **«قدم به قدم.»**

برخلاف ابزارهای بهره‌وری پرفشار، تِرَکشن به جای فهرست‌های طولانی و نمودارهای شلوغ، روی سه کار تمرکز دارد:

1. **برنامهٔ واقع‌بینانهٔ امروز:** فهرستی کوتاه از کارهایی که امروز واقعاً انجام‌شدنی هستند.
2. **شروع کار با تمرکز:** جلسهٔ تمرکز با زمان‌سنج و کمک برای وقتی که گیر کرده‌اید.
3. **دیدن پیشرفت:** هدف‌ها، عادت‌ها و مرور هفتگی و ماهانه به زبانی ساده و مهربان.

## مخاطب

- کسانی که کارهای بزرگ را به تعویق می‌اندازند و نمی‌دانند از کجا شروع کنند.
- کسانی که می‌خواهند روزشان را بدون فشار و احساس گناه برنامه‌ریزی کنند.
- کسانی که هدف‌های بلندمدت دارند (یادگیری زبان، برنامه‌نویسی، ورزش، پس‌انداز و…).

## قابلیت‌های اصلی

| بخش | قابلیت‌ها |
|---|---|
| **امروز** | خوشامدگویی با نام، کارت «آمادگی» (readiness)، کارهای امروز، شروع هوشمند، برنامهٔ روز، بازبینی پایان روز، پیشنهاد برنامه‌ریزی دوباره وقتی عقب افتاده‌اید |
| **برنامه‌ریزی** | برنامهٔ هفته، برنامهٔ ماه، مرور ماهانه با هوش مصنوعی |
| **هدف‌ها** | ساخت هدف، پیشرفت و وضعیت سلامت هدف، گام‌های بعدی، نقاط عطف (milestone)، شانس موفقیت، پیش‌بینی زمان پایان، برنامهٔ بازیابی |
| **تمرکز** | جلسهٔ تمرکز با طول تطبیقی، توقف و ادامه، «گیر کرده‌ام؟»، شکستن کار به گام‌های کوچک |
| **پیشرفت** | آمار هفته، پیشنهادها، عادت‌ها و الگوها (اهمال‌کاری، فرسودگی)، شتاب کار (momentum)، مرور هفتگی |
| **شما (پروفایل)** | لحن مربی (ملایم/متعادل/صریح)، ساعات کاری و انرژی، اعلان‌ها، مصرف هوش مصنوعی، ارسال بازخورد |
| **مدیریت** | داشبورد ادمین، مدیریت کاربران و نقش‌ها، دعوت‌نامه‌ها، آمار |

## اجزای پروژه

| جزء | فناوری | محل کد |
|---|---|---|
| سرور (API) | NestJS 11 + TypeScript | `backend/` |
| پایگاه داده | PostgreSQL + Prisma 7 | `backend/prisma/` |
| اپ موبایل و وب | Expo SDK 58 + React Native 0.88 + Expo Router | `apps/mobile/` |
| اپ بومی آیفون | Swift / SwiftUI | مخزن جداگانهٔ `traction-ios-app` |
| وب‌سایت معرفی | در برنامه | `apps/website/` (هنوز ساخته نشده) |
| هوش مصنوعی | OpenRouter (مدل‌های Claude) | `backend/src/modules/ai/` |
| میزبانی | Render (سرور و وب‌اپ) + Neon (پایگاه داده) | `render.yaml` |

| Traction | `github.com/AliMoradpour/Traction` | شاخهٔ کاری: `dev`؛ شاخهٔ اصلی: `main` |

## واژه‌نامهٔ کوتاه

| اصطلاح | معنی |
|---|---|
| API | رابطی که اپ از طریق آن با سرور حرف می‌زند |
| Expo | ابزاری برای ساخت اپ iOS، اندروید و وب با یک کد مشترک |
| PWA / وب‌اپ نصب‌شدنی | سایتی که می‌شود مثل اپ روی صفحهٔ اصلی گوشی نصبش کرد |
| Render / Neon | سرویس‌های ابری میزبانی سرور و پایگاه داده |
| Readiness | امتیاز آمادگی برای کار متمرکز، بر اساس رفتار اخیر |
| Momentum | شتاب کار؛ پیوستگی انجام کارها در روزهای اخیر |
