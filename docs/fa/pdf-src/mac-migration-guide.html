بخش ۱: پیش از کنار گذاشتن لپ‌تاپ ویندوزی

همهٔ کد تِرَکشن در گیت‌هاب است، اما چند چیز فقط روی همین لپ‌تاپ وجود دارد. این چک‌لیست را کامل کنید.

۱. خصوصی‌کردن مخزن

مهممخزن Traction هنگام نوشتن این راهنما عمومی بود. در گیت‌هاب: مخزن → Settings → General → Danger Zone → Change visibility → Private. پس از آن، فایل‌های .env.backup و مستندات را push کنید.

بخش ۲: راه‌اندازی مک‌بوک

دستورها را در Terminal اجرا کنید (⌘ + Space، بنویسید Terminal). نسخهٔ کامل و به‌روز: docs/fa/setup-mac.md

  1. Homebrew، Node، Git و Docker 
    /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
brew install node git
brew install --cask docker
open -a Docker
  2. Xcode را از App Store نصب کنید و یک بار باز کنید (برای اپ Swift).
  3. کلید SSH و اتصال به گیت‌هاب 
    ssh-keygen -t ed25519 -C "your-email"
pbcopy < ~/.ssh/id_ed25519.pub
    در گیت‌هاب: Settings → SSH and GPG keys → New SSH key → بچسبانید.
  4. دریافت پروژه‌ها 
    mkdir -p ~/Projects && cd ~/Projects
git clone git@github.com:AliMoradpour/Traction.git
git clone git@github.com:AliMoradpour/traction-ios-app.git
cd Traction && git checkout dev
  5. فایل‌های تنظیمات 
    cp backend/.env.backup backend/.env
cp apps/mobile/.env.backup apps/mobile/.env
ipconfig getifaddr en0
    نتیجهٔ دستور آخر، IP مک روی Wi-Fi است؛ آن را در apps/mobile/.env جای 192.168.1.6 بگذارید.
  6. پایگاه دادهٔ محلی 
    docker run -d --name traction-pg --restart unless-stopped \
  -e POSTGRES_PASSWORD=postgres -e POSTGRES_DB=traction \
  -v traction-pg-data:/var/lib/postgresql/data -p 5544:5432 postgres:17
  7. سرور 
    cd ~/Projects/Traction/backend
npm install && npx prisma generate && npx prisma migrate deploy
npm run start:dev
  8. اپ روی آیفون 
    cd ~/Projects/Traction/apps/mobile
npm install
npx expo login
npx expo start --lan --clear
    QR را با دوربین آیفون اسکن کنید (آیفون و مک روی یک Wi-Fi).
  9. Claude: برنامهٔ Claude را نصب و پوشهٔ ~/Projects/Traction را باز کنید. فایل CLAUDE.md خودکار خوانده می‌شود.
نشانهٔ موفقیتcurl http://localhost:3100/api/health پاسخ {"status":"ok"} می‌دهد و تِرَکشن روی آیفون از طریق Expo Go باز می‌شود.

پس از انتقال

  • برنامهٔ اپ Swift (docs/IOS_SWIFT_PLAN.md) برای ویندوز و xtool نوشته شده؛ با مک می‌توان آن را برای Xcode بازنویسی کرد که ساده‌تر و کامل‌تر است.
