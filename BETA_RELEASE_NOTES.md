# Traction Beta - Release Notes

## Version 1.0.0-beta.1

### What's New

#### Core Features
- **Today Screen**: Daily task management with dynamic greeting, task creation, and completion
- **Goals System**: Create, track, and manage goals with milestones and progress tracking
- **Focus Mode**: Timer-based focus sessions with distraction tracking
- **Behavioral Engine**: Track behavioral metrics and patterns
- **Execution Engine**: Task readiness, resistance analysis, and momentum tracking

#### AI Features
- **Daily Brief**: AI-powered morning briefing
- **Goal Recovery**: AI suggestions for getting back on track
- **Friction Analysis**: Identify and overcome blockers
- **Task Breakdown**: AI-assisted task decomposition
- **Weekly Review**: AI-generated weekly performance review

#### Beta-Specific Features
- **Beta Invite System**: Admins can invite new testers via email
- **Role-Based Access Control**: SUPER_ADMIN, ADMIN, BETA_TESTER, PREMIUM_USER, USER roles
- **Admin Dashboard**: User management, analytics, and system health
- **Feedback Widget**: In-app feedback submission (floating ? button)
- **Developer Settings**: Hidden debug panel (tap version 5 times on Profile)
- **Onboarding Flow**: Guided setup for new users
- **Welcome Carousel**: Feature introduction after onboarding

### How to Use

1. **Sign Up**: Use an invite code from your admin, or sign up directly
2. **Complete Onboarding**: Set your name, goals, experience level, and daily time
3. **Explore Features**: Check out Today, Goals, Focus, and Insights tabs
4. **Give Feedback**: Tap the floating ? button to report bugs or suggest features
